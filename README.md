# เว็บงานแผนงาน โรงเรียนพิษณุโลกพิทยาคม

หน้าเว็บที่ครูใช้เข้าระบบแผนงาน (ppksar) หาคู่มือ แบบฟอร์ม และเล่มแผนของปีงบปัจจุบัน

| ใช้ทำอะไร | ลิงก์ |
|---|---|
| **เปิดเว็บ** (ครูทุกคน) | https://pp-planning.github.io |
| **แก้ข้อมูลบนเว็บ** (ทีมแผน) | [Google Sheet หลังบ้าน](https://docs.google.com/spreadsheets/d/1BIRsO9rDHGSzYljjPZgdBGvRi4fYXIFs3T1SvQvTh5o/edit) |
| **โฟลเดอร์รวมทุกอย่างของเว็บใน Drive** (ทีมแผน) | [เว็บแผนงาน รรพพ](https://drive.google.com/drive/folders/14Vv6CpRTjoZB2O7SrrlZDZKAXhjMT9ga) · ในบัญชีโรงเรียนมีทางลัดอยู่ใน "2 แผนงาน รรพพ" |

ลิงก์ของทีมแผนเปิดได้เฉพาะบัญชีที่มีสิทธิ์

## แก้ข้อมูลบนเว็บยังไง

1. เปิด **Google Sheet หลังบ้าน**
2. แก้ในแท็บ `เอกสารและลิงก์` ได้ตรง ๆ หรือใช้เมนู **เว็บแผนงาน > แก้ไขข้อมูลเว็บ**
   - เพิ่มเอกสาร: ใส่หมวด ปีงบ ชื่อ คำอธิบาย ลิงก์ ป้ายบนปุ่ม และติ๊ก "ขึ้นหน้าแรก" ถ้าอยากให้อยู่หน้าแรก
   - ลิงก์ ppksar ชื่อเว็บ และอีเมลติดต่อ อยู่แท็บ `ตั้งค่าเว็บ`
3. บันทึกแล้วรีเฟรชเว็บ ข้อมูลเปลี่ยนตามเอง **ไม่ต้องแก้ไฟล์ใน GitHub**

**แบบฟอร์มที่ใช้คู่กับคู่มือ** ขึ้นใต้คู่มือเองตามชื่อ ไม่ต้องตั้งค่าเพิ่ม
- ชื่อคู่มือขึ้นต้นด้วย `คู่มือ PM3 — ...` (หมวด "คู่มือ")
- ชื่อแบบฟอร์มมี `PM3a-1`, `PM3a-2` ... และขีด `—` ตามด้วยคำอธิบาย เช่น `แบบฟอร์ม PM3a-1 — ชุดประกอบเล่มรายงานกิจกรรม` (หมวด "แบบฟอร์ม")
- ถ้าชื่อไม่ตรงรูปแบบนี้ แบบฟอร์มยังอยู่ในแท็บแบบฟอร์มตามปกติ แค่ไม่ขึ้นใต้คู่มือ

ไฟล์ใหม่ (PDF/Word) ให้อัปเข้าโฟลเดอร์ "คู่มือ PM และแบบฟอร์ม" ก่อน แล้วเอาลิงก์ไปใส่ใน Sheet

## ในที่เก็บนี้ (repo) มีอะไร

- `index.html` — ตัวเว็บทั้งหน้า สร้างอัตโนมัติ **ห้ามแก้ในนี้ตรง ๆ** เพราะรอบหน้าจะถูกเขียนทับ
- ต้นฉบับจริงอยู่ในเครื่องฝ่ายแผน โฟลเดอร์ `แผนงานโรงเรียน พพ/planning-site/` (อ่าน `STATE-planning-site.md` ก่อน)
  - แก้หน้าตา: `site/build_site.py` แล้วรัน `python3 planning-site/site/build_site.py --deploy`
  - โค้ดหลังบ้าน (Apps Script ที่ผูกกับ Sheet): `backend/`

## หลังบ้านทำงานยังไง

```
Google Sheet หลังบ้าน ──(Apps Script อ่านอย่างเดียว)──> หน้าเว็บ pp-planning.github.io
```

- เว็บดึงข้อมูลจาก Sheet ทุกครั้งที่เปิด ถ้าดึงไม่ได้จะใช้ข้อมูลชุดที่ฝังไว้ตอน build
- เว็บอ่านได้อย่างเดียว ไม่มีหน้าแอดมิน ไม่มีรหัสผ่าน และเขียนกลับ Sheet ไม่ได้
